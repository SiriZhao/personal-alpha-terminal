# 隐私与安全

- 应用默认仅监听 `127.0.0.1`，不提供公网服务。
- API Key 优先保存在 Windows Credential Manager，不进入仓库、日志、诊断包或普通备份。
- 诊断包不包含数据库，并自动脱敏 token、password、secret 和精确持仓金额字段。
- 外部 AI 默认不接收持仓证据；必须由用户显式启用，并可预览请求。
- Mock Provider 不发送外部请求，输出必须标为 Mock。
- 备份包含本地数据库、脱敏配置、组合/日志/研究索引，但不含密钥。
- 卸载默认保留 `%LOCALAPPDATA%\PersonalAlphaTerminal`；彻底删除前应手动备份。

本版本没有代码签名。请从受信任位置获取构建并验证 SHA256；不要上传包含密钥、token、完整持仓或个人交易记录的截图/日志。

尚未完成独立渗透测试、商业签名与全新 Windows VM 认证，因此本版本只用于项目所有者个人试用。
