# 用户手册

## 首页

Command Center 展示最后更新时间、A/HK/US 数据状态、质量门禁、运行模式、市场状态评分、组合摘要、历史证据和系统待办。统计结果只有在数据库存在真实计算结果且质量门禁允许时才展示。

## 运行模式

- Research Preview：允许接入真实数据和运行已通过门禁的研究。
- Mock Demo：仅测试流程；所有 Mock 结果必须带标识。
- Offline：不进行外部网络请求。
- Data Validation：用于数据导入和质量检查，不产生交易式结论。

## 研究页面

- 股票详情：价格、成交量和主数据；先检查币种、时区、复权口径。
- 事件研究：展示样本量、窗口、区间、冷却和可信等级。
- 条件概率：比较条件与无条件基准，关注 Probability Lift，不把概率写成预测。
- 市场关系/图谱/领先滞后：发现统计关系，不表示因果。
- 因子与 US Adaptive Alpha：只在 point-in-time 和质量门禁满足时形成研究等级。
- 回测与风险：使用下一可交易时点、成本、滑点与可交易性限制。

## 组合

可手工记录真实或模拟持仓；系统只分析，不执行交易。建议先设置是否允许诊断包排除精确金额，并保持“允许向外部 AI 发送持仓证据”关闭，除非确有需要。

## 设置

可设置主题、红绿习惯、运行模式、目标市场、AI Provider 与网络参数。密钥保存到 Windows Credential Manager。若系统无法使用 Credential Manager，保持 AI 禁用，不要把密钥写入配置文件。

## 诊断与备份

诊断包不包含数据库，配置与日志会脱敏。备份包含数据库、脱敏配置、组合和研究索引，不包含 API Key。恢复在下一次启动前执行，并先创建恢复前安全快照。

## 安全解读

“可用”表示代码路径可运行，不表示数据已认证；“验证中”表示仍有独立证据缺口；“已被安全门禁阻止”表示系统主动拒绝下游结论。历史或模拟结果不保证未来表现。
