# 数据源指南

## 当前路由合同

| 市场/资产 | Provider | 端点 | 状态 |
|---|---|---|---|
| A 股股票 | AKShare | `stock_zh_a_hist` | 可配置；真实认证未完成 |
| A 股 ETF | AKShare | `fund_etf_hist_em` | 安全禁用：成交量合同待认证 |
| A 股指数/债券 | AKShare | 独立端点 | 安全禁用 |
| 港股股票/ETF/指数 | Yahoo Finance | `yfinance.download` | 可配置；真实认证未完成 |
| 美股股票/ETF/指数 | Yahoo Finance | `yfinance.download` | 可配置；真实认证未完成 |
| 港/美债券 | Yahoo Finance | 独立债券合同 | 安全禁用 |

Provider 不得回退到股票接口。A 股股票研究库成交量单位为 `share`；收到 `hand` 或单位未知的数据必须在 Schema/Validation 层被拒绝。价格、币种、时区、交易日期和代码映射按市场隔离。

## 接入流程

1. 在首次启动或设置中选择市场。
2. 在“数据源”查看资产路由状态并运行本地配置合同检查。
3. Provider Raw 数据先进入规范化层，禁止直接写研究库。
4. 检查 OHLC 约束、成交量、重复、缺失、交易日、时区、币种、复权和公司行动。
5. 只有质量运行结果 PASS 的数据才能进入研究。

## 当前未关闭门禁

- 100+ A/HK/US 证券双源抽样认证未完成。
- 点时退市样本、成分股快照和公司行动账本未完成真实源认证。
- 分红、拆股与复权的跨源历史对账未完成。
- 真实 2008/2020/2022/2023–2025 冻结数据验证未完成。

因此“Provider 可连接”不等于“数据已认证”。不要把样例或 Mock 数据用于真实研究结论。
