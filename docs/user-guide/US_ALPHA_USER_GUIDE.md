# US Adaptive Alpha 用户指南

## 当前用途

这是研究页面，不是下单页面。当前版本只允许查看数据门禁、可用/禁用 Sleeve、信号拆解、风险削减和追溯信息。真实数据认证与冻结样本外验证尚未完成，因此不应据此投入真实资金。

## 页面阅读顺序

1. **数据状态**：必须先看 PASS/DEGRADED/BLOCKED。BLOCKED 时所有风险资产建议区间应为 0%–0%。
2. **可用策略**：只表示当前能力契约满足，不表示策略有 Alpha。
3. **禁用原因**：例如缺 PIT fundamentals、earnings 时间、OOS calibration；系统不会 fallback 到股票价格替代。
4. **基础信号**：来自独立 Sleeve，不与其他 Sleeve 机械相加。
5. **条件证据**：比较条件与无条件基准，重点看 Lift、样本、ESS、区间、成本后期望和新鲜度。
6. **市场状态**：未校准时显示 Market Regime Score，不是概率。
7. **风险削减**：展示行业、相关簇、流动性、Beta、Top-5、Regime 和 Momentum Crash 的削减。
8. **最终研究等级**：历史证据增强、正向证据、中性、负向证据、证据不足、风险受限或暂不进入组合。
9. **建议仓位区间**：研究约束输出，不是交易指令；初始真实资金比例必须由人决定。
10. **追溯入口**：使用 trace IDs 定位数据快照、事件、统计检验和计算时间。

## 阶段门禁

Stage 1 历史研究 → Stage 2 冻结参数 OOS → Stage 3 前向观察 → Stage 4 影子记录 → Stage 5 极小资金人工执行 → Stage 6 逐步扩大。

进入下一阶段需要数据 PASS、冻结参数、基准完整、成本纳入、足够运行天数和零未解决严重事故。系统永不自动决定真实资金比例，也不自动下单。

## 正确解释

“正向证据”表示历史条件下相对基准存在经门禁后的增量证据，不表示未来必涨。“证据不足”是有效结论，不应通过降低样本标准或添加条件强行生成信号。“现金”用于降低风险资产暴露，但仍有通胀、货币、托管和对手方风险。

## 运行

按项目 README 初始化数据库并启动 Streamlit 后，从导航进入 **US Adaptive Alpha**。没有真实数据库时页面应安全显示 BLOCKED，而不是展示 Mock 投资机会。
