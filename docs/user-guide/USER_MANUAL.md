# Personal Alpha Terminal 用户手册

## 1. 第一次启动

1. 推荐双击 `PersonalAlphaTerminal-0.1.0-Setup.exe` 完成当前用户安装；也可解压便携 ZIP。
2. 从开始菜单启动，或双击便携目录中的 `PersonalAlphaTerminal.exe`。
3. 程序自动检查目录权限、磁盘空间、配置和数据库迁移，然后打开浏览器。
4. 默认地址为 `http://127.0.0.1:8501`；端口被占用时程序会自动选择其他本地端口。

终端只监听本机回环地址，不向局域网开放。关闭浏览器不会关闭后台进程；请双击
`Stop Personal Alpha Terminal.cmd`。

用户无需安装 Python。首次启动结果保存在
`%LOCALAPPDATA%\PersonalAlphaTerminal\startup-status.json`；数据库和配置在卸载后默认保留。

## 2. 先看首页

首页依次展示：

- 全球市场：主要指数最新收盘、日变化和成交量。
- 市场状态：Risk-On / Neutral / Risk-Off 与模型证据质量。
- 历史事件线索：历史条件下的上涨频率、样本数和证据质量。
- 组合风险：当前价值、波动、最大回撤和 Beta。
- 风险与数据状态：数据陈旧、Risk-Off、回撤阈值等提醒。

页面不会用模拟数据填补空白。空卡片表示数据库尚无相应研究结果。

## 3. 股票与搜索

进入“股票详情”，在选择框输入代码或名称即可搜索。选择时间范围后查看：

- 复权价格趋势；
- 成交量；
- 证券主数据、市场、币种、行业；
- 数据来源和最后交易日。

用于收益的曲线是复权收盘价；当日 OHLC 原始字段仍保存在数据库中。

## 4. 研究模块

### 事件研究

先保存版本化事件定义，再选择触发资产、目标资产和日期。结果中的“上涨概率”是历史频率，
不是未来预测。样本可能随期限增加而减少，因为未走完前瞻窗口的事件不进入分母。

### 条件概率

系统默认至少 30 个非重叠事件样本。未达到门槛时，概率和区间显示为空，不能用于决策。
Wilson 区间描述二项比例的不确定性，但不能消除市场状态变化和选择偏差。

### 因子研究

动量和波动使用复权收益；PE/PB 直接使用点时财务记录；FCF Yield 使用原始市场价格。
财务记录只有在 `available_at` 早于对应市场收盘时才可见。

### 相关、图与领先滞后

相关性页面适合观察结构变化；Lead-Lag 使用 Granger 检验并对滞后搜索和资产对执行
多重检验校正。市场图中的“资金传导”目前是收益与异常成交量代理，不是真实订单流。

### 市场状态

第一版是滚动标准化统计模型，Softmax 输出尚未经过真实标签校准。因此证据质量最高为 50%，
不能把模型概率理解为客观发生概率。

## 5. 组合与风险

持仓使用日期快照。多币种组合必须准备 FX 数据；系统不会直接把 CNY、HKD 和 USD 相加。
组合历史风险是“当前权重回放”，不是账户真实历史业绩。

压力测试是静态敏感度：

```text
持仓市场冲击 = Beta × 基准冲击
组合冲击 = (1 + 市场冲击) × (1 + 汇率冲击) - 1
```

没有有效 Beta 的权重显示为未覆盖，不会假设 Beta=1。

## 6. 情景模拟

进入“情景模拟”前，先在“基础风险”页面完成一次组合估值。模拟器使用该已完成快照，不会
把不同日期的持仓与估值混合。

使用顺序：

1. 选择投资组合，确认快照日期和基准币种。
2. 展开“资产—风险因子映射”，检查覆盖率、来源和截至日期。
3. 对没有映射的资产录入有依据的中心敏感度、上下界、方法和来源；不要凭感觉补数。
4. 选择内置模板，或录入百分比、利率基点、标准分和直接汇率假设。
5. 查看组合变化、风险等级、映射覆盖率、证据质量、风险地图和逐资产贡献。
6. 使用多情景比较观察同一当前组合在不同条件下的损失差异。

`证据质量 80/100` 不代表情景有 80% 概率发生。未映射资产按不变处理，会低估风险。
2008、2020、2022 是待重新校准的近似模板；AI 估值回撤不是历史事件。详细方法见
[Scenario Simulator](SCENARIO_SIMULATOR.md)。

## 7. 数据更新与故障

- 网络/API 失败：更新任务会重试并逐证券隔离，失败不会覆盖已有历史数据。
- 停牌：没有新交易记录是正常情况；系统不会生成零收益交易日。
- 新股：历史不足时研究模块会拒绝计算。
- 休市：允许无新数据，但首页会显示最后数据日期。
- 退市：需将 `is_active=false` 并记录 `delist_date`；当前没有自动退市主数据源。

日志位于 `%LOCALAPPDATA%\PersonalAlphaTerminal\logs`。

## 8. 更新

在 `config.env` 设置：

```dotenv
PAT_UPDATE_MANIFEST_URL=https://your-domain.example/pat/latest.json
```

清单格式：

```json
{"version":"0.1.1","url":"https://.../PAT-0.1.1.zip","sha256":"..."}
```

更新程序只下载并校验到 `updates` 目录，不会静默替换正在运行的二进制。当前没有公共更新源。

## 9. 决策前检查

每次使用研究结论前确认：

1. 数据日期、市场、代码和来源正确。
2. 原始价/复权价用途正确。
3. 样本数达到门槛，置信区间不过宽。
4. 没有把证据评分当成预测成功率。
5. 回测区间没有重叠，财务数据满足点时可见性。
6. 退市、停牌、交易成本、税费和流动性限制已单独考虑。
