# Momentum Crash Monitor

## 目的

监测动量策略在市场急跌后反弹、高 Beta loser 反转、波动和相关性聚集时的脆弱性。它是风险监视器，不是崩盘预测器，也不使用单一二元开关。

## 输入与实现

v0.1 接收九个归一化到 `[0, 1]` 的可解释指标：大跌后反弹、winner-loser Beta 差、空头压力、横截面离散度、高波动状态、动量因子回撤、估值拥挤、行业集中和相关性急升。

至少五个指标可用时，按公开权重计算连续分数，并输出 low/elevated/high 研究标签、逐项贡献、Momentum Sleeve 乘数和总风险乘数。缺失指标不会被填成安全值；指标不足时返回 unavailable，同时应用保守不确定性折扣。所有输入必须来自当时可获得的数据。

允许的响应包括逐步降低动量权重、总风险和高 Beta 新增仓位，增加分散或现金。禁止因一天标签改变全仓切换；最终变化还受 Regime 确认、冷却期和单日仓位变化限制。

## 限制与状态

代码和场景测试已实现；真实 short-interest point-in-time、赢家拥挤估值、历史动量因子收益和流动性状态尚未认证。当前分数只能用于研究与压力检查，不能作为真实资金执行信号。固定权重是透明初值，须用冻结数据做参数扰动和 OOS 验证；未证明稳定前不得优化为黑盒模型。
