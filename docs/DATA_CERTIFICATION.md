# Data Certification

The authoritative machine-readable records are
`docs/development/DATA_CERTIFICATION_STATUS.json` and `DATA_GAPS.json`.

Live/free-provider price retrieval may support display and data-pipeline diagnostics. It does
not certify historical membership, delistings, point-in-time corporate actions, fundamental
restatements, or index total return. Provider adjusted close is never accepted as PIT total
return. Current-survivor replay is rejected. A single provider is not dual-source certification.
