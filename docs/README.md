# Personal Alpha Terminal documentation

Documentation is organized by purpose:

- root `README.md`, `ARCHITECTURE.md`, `REPOSITORY_GUIDE.md`, `TECH_DEBT.md`: current truth.
- `architecture/`: system and module design notes.
- `user-guide/`: setup, operation, data-source, AI-provider, and troubleshooting guides.
- `reports/`: generated audit, data, strategy, validation, security, and release records.
- `development/`: maintainer-facing development notes.
- `audits/`: current audit and closure records, including ROUND27/ROUND28.
- `history/`: superseded session reports; not current truth.

Run evidence is maintained under `reports/daily-runs/` and
`reports/validation-artifacts/`. Reports are research and engineering records;
they do not override the live data gate or imply production approval.
