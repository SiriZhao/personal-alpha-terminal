# Personal Alpha Terminal 1.0.0-test

这是供项目所有者进行真实功能测试的 Windows 本地测试版，不是实盘认证版本，也不构成投资建议。

## 启动

1. 完整解压 ZIP；不要只复制 EXE，也不要在压缩软件预览窗口中运行。
2. 双击 `Personal_Alpha_Terminal.exe`。
3. 程序会在本机回环地址启动服务，并自动打开默认浏览器。
4. 首次启动会在 `%LOCALAPPDATA%\PersonalAlphaTerminal` 创建配置、SQLite 数据库、日志、备份和诊断目录。

程序包和用户数据严格分离。删除或升级程序目录不会自动删除用户数据库。

## 首次使用

- 在“设置”中配置市场数据源。
- AI Provider 为可选项；没有 API Key 时系统仍可运行。
- 在“我的组合”中手动录入持仓或导入 CSV。
- 数据质量门禁未通过时，系统只显示 `Research Only / No Decision Generated`，不会伪造投资行动。

## AI 密钥

API Key 不在 EXE、配置模板或 ZIP 中。Windows 下使用 Credential Manager 保存，日志和诊断包会脱敏。不要把密钥写入项目文件或普通配置文件。

## 关闭与重启

关闭浏览器标签页不会停止本地服务。请再次启动程序并使用系统内的关闭入口，或运行随包提供的停止命令。重新双击 EXE 会连接现有实例，不会重复启动后台服务。
